# Recruitment Strategy & Workforce Planning

## Project Overview

This project is a data-driven Recruitment Strategy and Workforce Planning system developed using Python.

The project analyzes workforce requirements and recruitment data to support hiring and workforce planning decisions.

## Key Features

- Workforce Dataset Analysis
- Department-wise Hiring Gap Analysis
- Workforce Requirement Forecasting
- Candidate Recruitment and Selection System
- Weighted Candidate Scoring
- Automatic Hiring Recommendations
- Candidate Performance Analysis
- Recruitment KPI Dashboard
- Quarterly Hiring Forecast
- Smart Recruitment Priority Analysis
- Final Management Dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Files

- Recruitment_Strategy_Workforce_Planning_Project.ipynb
- employee_workforce_data.csv
- candidate_recruitment_data.csv
- workforce_gap_analysis.csv
- recruitment_kpi_dashboard.csv
- quarterly_hiring_forecast.csv
- recruitment_priority_analysis.csv

## Project Outcome

The system identifies workforce gaps, evaluates candidates using a weighted scoring framework, monitors recruitment KPIs, forecasts quarterly workforce requirements, and identifies departments that should be prioritized for recruitment.

## How to Run

1. Open the `.ipynb` file in Google Colab or Jupyter Notebook.
2. Run all cells from top to bottom.
3. The system will generate workforce analysis, candidate recommendations, KPI analysis, forecasts, and visualizations.
